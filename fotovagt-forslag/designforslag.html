Fotovagt: designforslag

Et forslag til, hvordan Marken og Kontoret kan se ud med en strammere farvebrug, bedre kontrast og mere plads til det vigtige. Siden står alene og ændrer ikke appen. Tokens øverst i filen kan bruges som ny start på style.css.

1. Farver: én regel for rød, og tekst der kan læses

Regel: mættet rød flade bruges kun til SOS. Status vises som tonede chips med mørk tekst (alle par er mindst 4,5:1). "Optaget" flyttes til rødorange, så den ikke kan forveksles med SOS på kortet. Hver status har tre tokens: fyld (prik, kant, nål), tonet baggrund og tekst.

I dag: hvid tekst på "Ny"-orange er 2,6:1, og den gule .advarsel-tekst på hvid er 1,6:1. Med forslaget er alle chips over 4,5:1, i både lys og mørk tilstand.

Hvad er ændret

  1. Status i toppen som segmentkontrol (44 px høj i stedet for ca. 76 px). Hændelserne starter ca. 90 px højere oppe. Den valgte status har samme tonede farve som chippen ved navnet.
  2. Navnet til venstre, SOS til højre. Den tomme plads ved logoet bruges. SOS bliver i hjørnet, hvor tommelfingeren er, og er stadig 48 px høj.
  3. Afstand og køretid er det største tal på kortet, lige ved knappen. "Nærmest" er standardsortering i marken.
  4. Status som pille øverst til højre i stedet for "Ledig opgave" brudt over to linjer.
  5. Høj prioritet vises med et lille "!" og en rødlig kant, ikke med rød flade.
  6. "Tag opgaven" i stedet for "Tag". Opgaver, som andre har taget, viser "Sofie er på vej" i stedet for knappen.
  7. Offline-bjælke (forslag 3.5): fotografen kan se, at status venter på net.

3. Kontoret: én række i toppen

4. Opbygning af style.css

Forslag til rækkefølge med @layer, så nye regler ikke skal lægges nederst for at "vinde", og så de dobbelte regler kan samles.

@layer tokens, base, komponenter, marken, kontor, sos, hjaelpere; @layer tokens { :root { /* farver, skala, skygger (som øverst i denne fil) */ } } @layer base { *, body, h1–h4, a, :focus-visible, input/select/textarea } @layer komponenter{ knap, chip, pille, ark/dialog, toast, h-kort, tidslinje, kort/nåle } @layer marken { body.marken … (topbjælke, segmentkontrol, faner, liste) } @layer kontor { body.kontor … (grid, paneler, top med Værktøjer-menu, rapport) } @layer sos { .sos-knap, .sos-boks, dialog.sos-dialog, .sos-pin } @layer hjaelpere { [hidden], .kun-smal/.kun-bred, .skjult-label, reduced-motion } /* Dark mode for kortfliser, når der ikke bruges et mørkt kortlag */ @media (prefers-color-scheme: dark) { .leaflet-tile-pane { filter: invert(1) hue-rotate(180deg) brightness(.9) contrast(.9); } }
